🛡️ Defense Suite

Plateforme de détection multi-fonctions — anti-phishing · fichiers · réseau · fuites de données

Analyse d'URL / anti-phishing

Détecte le typosquatting, les certificats invalides, les domaines récents et les indicateurs classiques de phishing.

Analyse de fichiers

Vérifie le hash, le type réel du fichier, l'entropie (packing/chiffrement), les macros Office et VirusTotal (si configuré).

Monitoring réseau

Scan léger des ports communs d'un hôte.

⚠️ Les hôtes privés/locaux (127.0.0.1, 10.x, 172.16-31.x, 192.168.x) sont scannables librement. Les domaines et adresses IP publics exigent une vérification technique de propriété (DNS ou fichier HTTP) avant tout scan — voir ci-dessous.

🔐 Vérification de propriété requise

Cette cible est publique. Prouvez que vous la contrôlez avant de pouvoir la scanner.

Vérification de mot de passe compromis

Vérification par k-anonymity (HaveIBeenPwned) — votre mot de passe complet n'est jamais envoyé.

Analyse d'authenticité d'email

Détecte les adresses/domaines usurpés ou frauduleux (absence de serveurs mail, SPF/DMARC manquants, imitation de marque) — signal typique des emails utilisés pour le phishing, la diffusion de virus ou le piratage de compte.

Vérification d'email compromis

Nécessite une clé API HaveIBeenPwned (payante). Sans clé, un lien manuel est fourni.
